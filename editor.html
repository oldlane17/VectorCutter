About SVG Editor

SVG Editor is a powerful web-based tool for creating and editing Scalable Vector Graphics.

Features include:

  • Multiple shape tools
  • Cartesian coordinate system
  • Real-time property editing
  • Drag and drop element movement
  • Movable map with panning
  • Multiple unit systems (px, mm, cm, in)
  • Export to SVG and PNG
  • Resize handles for elements
  • Rotate functionality
  • And more...
